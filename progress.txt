## 2026-03-23 - File System 标签页加载问题修复
- 问题：初次打开 File System 标签时数据不显示，需要切换其他菜单后再回来
- 根因：`onHello` 回调中缺少 `loadChannels` 调用，导致 `channels.snapshot` 不完整
- 解决：在 `ui/src/ui/app-gateway.ts` 的 `onHello` 回调中添加 `void loadChannels(host as unknown as OpenClawApp)`
- 参考：lessons.md 中"菜单可见性配置加载时序问题"的经验
- 修改文件：`ui/src/ui/app-gateway.ts`
